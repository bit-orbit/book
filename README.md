# کتاب‌های تخصصی مهندسی و دواپس (Open DevOps & Systems Books Hub)

پورتال جامع ترجمه و تفسیر تخصصی معتبرترین کتاب‌های مهندسی نرم‌افزار، دواپس (DevOps)، رایانش ابری (Cloud-Native) و معماری سیستم‌ها به زبان فارسی فنی (**Developer Persian**).

---

## 🌟 ویژگی‌های برجسته
- **تفسیر مفهومی و عمیق:** پرهیز کامل از ترجمه کلمه‌به‌کلمه و ماشینی؛ بازنویسی منطق مهندسی و تجربیات پروداکشن برای جامعه توسعه‌دهندگان ایرانی.
- **ادبیات استاندارد مهندسی (Developer Persian):** استفاده از اصطلاحات اصیل صنعتی (اسکیل، دیپلویمنت، پایپ‌لاین، کش، اینگرس و...) به‌جای معادل‌های نامأنوس تحت‌اللفظی.
- **صفحه‌آرایی مدرن با Typst:** تولید کتاب‌های الکترونیکی نفیس و استاندارد با کیفیت چاپ با موتور قدرتمند Typst و قلم وزیرمتن (Vazirmatn).
- **معماری ماژولار و ساب‌ماژول:** هر کتاب در مخزن مجزای خود توسعه می‌یابد و به این پورتال متصل می‌شود.

---

## 📚 ساختار مخزن (Federated Hub & Submodules)

این مخزن به عنوان **هاب مرکزی و وب‌سایت پورتال (با استفاده از Hugo)** عمل می‌کند و کتاب‌ها به صورت **Git Submodule** به آن اضافه می‌شوند:

```text
book/ (Hub Repository)
├── .agents/                      # قوانین، پرامپت‌ها و اسکیل‌های هوش مصنوعی
├── content/                      # محتوای صفحات سایت Hugo
├── books/                        # ساب‌ماژول‌های اختصاصی هر کتاب
│   └── the-kubernetes-book-2025  # کتاب کوبرنتیز ۲۰۲۵ (ویرایش فارسی)
├── layouts/                      # تم و قالب‌های وب‌سایت
├── static/                       # فایل‌های استاتیک، فونت‌ها و تصاویر وب
├── AGENTS.md                     # راهنمای جامع تعامل هوش مصنوعی با پروژه
└── ARCHITECTURE.md               # تشریح کامل معماری فنی، ساختار و پایپ‌لاین CI/CD
```

## 🚀 نحوه اجرا و توسعه محلی

### ۱. کلون کردن مخزن به همراه تمام کتاب‌ها (Submodules)
```bash
git clone --recursive https://github.com/your-username/book.git
cd book
```

اگر قبلاً کلون کرده‌اید:
```bash
git submodule update --init --recursive
```

### ۲. اجرای وب‌سایت هاب با Hugo
```bash
hugo server -D
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:1313/` بروید.

### ۳. کامپایل PDF کتاب‌ها با Typst
برای کامپایل هر کتاب وارد پوشه همان کتاب در `books/` شوید:
```bash
cd books/the-kubernetes-book-2025
typst compile --font-path fonts book.typ The-Kubernetes-Book-2025-Persian.pdf
```
