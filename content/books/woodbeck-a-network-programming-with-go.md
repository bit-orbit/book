## درباره این کتاب

کتاب **Network Programming with Go: Code Secure and Reliable Network Services** اثر **آدام وودبک (Adam Woodbeck)** یکی از مراجع معتبر و کلیدی در این حوزه است. این کتاب در حال حاضر در صف ترجمه و بازتفسیر آزاد قرار دارد.

### سرفصل‌های کتاب جهت ترجمه:
- **فصل ۱:** مروری بر سیستم‌های شبکه‌ای و مدل لایه‌ای
- **فصل ۲:** مسیریابی و تفکیک ترافیک شبکه
- **فصل ۳:** استریم‌های داده مطمئن بر بستر پروتکل TCP
- **فصل ۴:** ارسال و دریافت پیشرفته داده‌ها در TCP
- **فصل ۵:** ارتباطات سبک و غیرمتصل UDP
- **فصل ۶:** ایجاد قابلیت اطمینان بر بستر UDP
- **فصل ۷:** سوکت‌های یونیکس (Unix Domain Sockets)
- **فصل ۸:** توسعه کلاینت‌های منعطف و قدرتمند HTTP
- **فصل ۹:** طراحی و توسعه وب‌سرویس‌های HTTP
- **فصل ۱۰:** بررسی وب‌سرور مدرن Caddy
- **فصل ۱۱:** امنیت ارتباطات شبکه با استفاده از پروتکل TLS
- **فصل ۱۲:** سریال‌سازی داده‌ها و پروتکل‌های باینری
